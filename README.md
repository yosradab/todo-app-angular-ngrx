# Todo App Angular avec NgRx

Application simple de gestion de tâches avec Angular 19 (standalone), NgRx, et Bootstrap.

## Fonctionnalités
- Connexion mock par email.
- Gestion des tâches (ajouter, modifier, supprimer, valider).
- Tâches utilisateur-spécifiques (filtrées par email).
- Déconnexion : efface les tâches et redirige.
- UI responsive avec Bootstrap.

## Installation
1. Clonez : `git clone https://github.com/yosradab/todo-app-angular-ngrx.git`
2. Installez : `npm install`
3. Lancez : `ng serve`

## Structure
- `auth/` : Connexion mock.
- `tasks/` : Gestion des tâches avec NgRx.
- `main.ts` : Bootstrap standalone.
